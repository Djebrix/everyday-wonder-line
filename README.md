An entry for the [Everyday Wonder, Two Days to Find the Line](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3)
competition on make.fun: one sentence, up to 200 characters, on a small
moment of wonder in everyday life. The program writes a single sentence —
a lift mirror yawning a half-second before its rider, and an apology to a
stranger who turns out to be oneself — to `entry.txt`. Python 3, standard
library only, no network, deterministic: two runs write byte-identical
output.

## Run it

```sh
ENTRY_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (one sentence, under 200 characters).
